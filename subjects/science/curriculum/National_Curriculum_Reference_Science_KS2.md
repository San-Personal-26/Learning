# National Curriculum Reference — Key Stage 2 Science

Source: DfE "National curriculum in England: science programmes of study" — Key Stage 2 subject content (https://www.gov.uk/government/publications/national-curriculum-in-england-science-programmes-of-study/national-curriculum-in-england-science-programmes-of-study).

Structured the same way the maths reference (`CURRICULUM_REFERENCE.md`) was — lettered main sections, numbered subsections — so each can be used as a short code, e.g. `C.6`, for lesson content to cite per CLAUDE.md's "cite the National Curriculum objective" rule.

**Important caveat:** unlike Key Stage 1 and Key Stage 3, the DfE source document *does* split Key Stage 2 statements out by individual year group — "lower key stage 2" (Years 3–4) and "upper key stage 2" (Years 5–6), with separate programme-of-study statements for Years 3, 4, 5 and 6. Per this project's decision, this reference deliberately flattens that split: statements are grouped by **content strand** (Plants, Rocks, Light, etc. — mirroring how the maths KS3 reference groups by strand rather than by year) rather than kept in four separate year blocks, and the original document order is preserved within each strand. Deciding which refs belong to which specific year is therefore a sequencing decision for this project to make later, exactly as with Year 8 maths — this file does not lose that information, it simply isn't split out yet. Where a strand's statements originate from more than one year (e.g. "Animals, including humans" appears in Years 3, 4, 5 and 6), a `[Y3]`/`[Y4]`/`[Y5]`/`[Y6]` tag is kept next to each statement for that reason.

**"Working scientifically" note:** as with KS1 and KS3, these are not a standalone unit — they describe the practical methods, processes and skills to be taught *through* the content strands below. The source gives a slightly more advanced set of these for Years 5–6 than for Years 3–4; both are included below in document order, tagged by year block.

**Sub-skill breakdowns** under each table are draft v1 — a further, lesson-sized decomposition of each broad NC statement, written independently for this project (not sourced from any third-party scheme). They're a starting point to refine as actual lesson content gets built, not a final spec. Refs follow the pattern `C.6.1` (strand C, NC statement 6, sub-skill 1).

## A. Working Scientifically

| Ref | Statement |
|---|---|
| A.1 | Ask relevant questions and use different types of scientific enquiries to answer them [Y3–4] |
| A.2 | Set up simple practical enquiries, comparative and fair tests [Y3–4] |
| A.3 | Make systematic and careful observations and, where appropriate, take accurate measurements using standard units, using a range of equipment, including thermometers and data loggers [Y3–4] |
| A.4 | Gather, record, classify and present data in a variety of ways to help in answering questions [Y3–4] |
| A.5 | Record findings using simple scientific language, drawings, labelled diagrams, keys, bar charts, and tables [Y3–4] |
| A.6 | Report on findings from enquiries, including oral and written explanations, displays or presentations of results and conclusions [Y3–4] |
| A.7 | Use results to draw simple conclusions, make predictions for new values, suggest improvements and raise further questions [Y3–4] |
| A.8 | Identify differences, similarities or changes related to simple scientific ideas and processes [Y3–4] |
| A.9 | Use straightforward scientific evidence to answer questions or to support their findings [Y3–4] |
| A.10 | Plan different types of scientific enquiries to answer questions, including recognising and controlling variables where necessary [Y5–6] |
| A.11 | Take measurements, using a range of scientific equipment, with increasing accuracy and precision, taking repeat readings when appropriate [Y5–6] |
| A.12 | Record data and results of increasing complexity using scientific diagrams and labels, classification keys, tables, scatter graphs, bar and line graphs [Y5–6] |
| A.13 | Use test results to make predictions to set up further comparative and fair tests [Y5–6] |
| A.14 | Report and present findings from enquiries, including conclusions, causal relationships and explanations of and degree of trust in results, in oral and written forms such as displays and other presentations [Y5–6] |
| A.15 | Identify scientific evidence that has been used to support or refute ideas or arguments [Y5–6] |

### Sub-skill breakdown (draft v1)

- **A.1** — A.1.1 Turn a curiosity into an answerable scientific question · A.1.2 Choose an enquiry type (observe over time, comparative/fair test, identify & classify, research) to suit the question
- **A.2** — A.2.1 Set up a simple comparative test · A.2.2 Identify what to keep the same to make a test fair
- **A.3** — A.3.1 Make careful, sequenced observations · A.3.2 Take a measurement using a standard unit and appropriate equipment
- **A.4** — A.4.1 Gather data using a table or tally · A.4.2 Classify gathered data into groups · A.4.3 Present data as a simple chart
- **A.5** — A.5.1 Record findings with correct scientific vocabulary · A.5.2 Produce a labelled diagram or simple bar chart of results
- **A.6** — A.6.1 Give a short oral report on an enquiry · A.6.2 Write up findings and a conclusion
- **A.7** — A.7.1 Draw a conclusion from results · A.7.2 Predict a new value from a pattern in results · A.7.3 Suggest one improvement or a follow-up question
- **A.8** — A.8.1 Spot a difference or similarity between two observations · A.8.2 Link an observed change to a simple scientific idea
- **A.9** — A.9.1 Use evidence gathered to answer the original question
- **A.10** — A.10.1 Plan an enquiry, choosing a suitable type · A.10.2 Identify the variable to change, measure and control in a fair test
- **A.11** — A.11.1 Take an accurate measurement with suitable equipment · A.11.2 Take repeat readings and use them appropriately
- **A.12** — A.12.1 Record more complex data in a table · A.12.2 Plot results on a scatter, bar or line graph
- **A.13** — A.13.1 Use a result to predict the outcome of a further test · A.13.2 Design a follow-up comparative or fair test
- **A.14** — A.14.1 Explain a causal relationship shown by results · A.14.2 State how much trust to place in a set of results and why
- **A.15** — A.15.1 Decide whether given evidence supports or contradicts a claim
